---
title: Tuning recall
description: See why a memory does or does not come up, change the ranking, and measure the result with a cases file.
---

The ranking defaults are first guesses. Tune them against real conversations:
look at one query, write down what should come up, then change a value and
compare.

## Look at one query

```sh
clanka recall ~/.config/clanka/souls/<id>.md "Is the Old well safe to drink from?"
```

```text
0.62 relevance, 0.74 score  #4 [open_thread, normal] The Old well is to be opened. Nobody's drawn from it in twenty years and it was capped for a reason. I want to know the reason, and what Corvin will do if the water runs foul.
0.30 relevance, 0.30 score  #3 [user_fact, normal] Corvin Dunmore means to open the Old well again rather than walk the hour a day to the Market well. I want the reason it was capped before he lifts the boards.
0.38 relevance, 0.29 score  #5 [user_fact, faint] They still have my good knife from the honey harvest and keep forgetting to bring it back. I told them to keep it till harvest — I'd rather have it back before I go poking at that well.
3 of at most 8 memories (min_relevance 0.25, min_score 0.05).
```

That is Kestrel after one evening. The knife came up because the memory
mentions a well.

[`clanka recall`](/cli/recall/) runs the same search a turn runs, on the
query alone. For each memory it prints the relevance (how close the memory is
to the query) and the final score after level, age, mood and open threads.
It also prints the limits in use.

It only reads the memory. Nothing is marked as recalled.

## Write the cases

Put the queries and what each should bring up in a TOML file:

```toml
[[case]]
query = "Is the Old well safe to drink from?"
expect = ["Old well"]
reject = ["knife"]

[[case]]
query = "How is the Dunmore girl?"
expect = ["grey spots"]

[[case]]
query = "Did I ever give back your knife?"
expect = ["knife"]
```

- `expect` lists texts that must appear in a recalled memory or in the value
  of one of its facts, in any letter case.
- `reject` lists texts that must not.

A case needs at least one of the two.

## Measure

```sh
clanka eval ~/.config/clanka/souls/<id>.md cases.toml
```

[`clanka eval`](/cli/eval/) prints each case, then how many expected
memories came up and their mean reciprocal rank. It exits non-zero on a miss
or an unwanted memory, so it works in a script.

```text
"Is the Old well safe to drink from?": 3 recalled
  ok    "Old well" at 1
  NOISE "knife" at 3
"How is the Dunmore girl?": 4 recalled
  ok    "grey spots" at 1
"Did I ever give back your knife?": 2 recalled
  ok    "knife" at 1

3 of 3 expected memories came up (mean reciprocal rank 1.00); 1 unwanted.
```

## Change a value and compare

Set a key under [`[recall]`](/configuration/#recall) in `config.toml`, then
run the eval again:

```toml
[recall]
min_relevance = 0.4
```

```text
"Is the Old well safe to drink from?": 1 recalled
  ok    "Old well" at 1
"How is the Dunmore girl?": 4 recalled
  ok    "grey spots" at 1
"Did I ever give back your knife?": 1 recalled
  ok    "knife" at 1

3 of 3 expected memories came up (mean reciprocal rank 1.00); 0 unwanted.
```

The knife is gone, but so is Corvin's memory, which was below 0.4 too. The
cases didn't ask for it, so the eval can't see what was lost; add an
`expect` for everything a query should bring up.

Some starting points:

| Symptom                                      | Try                                            |
| -------------------------------------------- | ---------------------------------------------- |
| Unrelated memories come up                   | Raise `min_relevance`.                         |
| A name or place does not bring up its memory | Raise `fts_weight`.                            |
| Old memories never come up                   | Raise `faint_half_life` or `normal_half_life`. |
| The same seared moments come up every turn   | Lower `seared_limit`.                          |
| Too much memory in each turn                 | Lower `limit`.                                 |

A process that has the companion open keeps the values it loaded. Restart it
to pick up the change.

## Other languages

The default embedding model is English. For companions that talk in other
languages, switch to the multilingual one and rebuild the vectors:

```toml
[embedding]
model = "multilingual"
```

```sh
clanka embedding
clanka doctor reembed ~/.config/clanka/souls/<id>.md
```

Models spread similar texts differently, so
[`duplicate_similarity`](/configuration/#duplicate_similarity) may need
changing with the model.
