title: Traits and persona changes

A `soul.md` is one Markdown file per companion, under
`~/.config/clanka/souls/`. It has two parts: TOML frontmatter between `+++`
lines, and a Markdown body.

```markdown
+++
id = "…"
name = "Nova"
contrariness = 0.5
persistence = 0.5
time_sense = true
recall_window = 2
drift = 0.3
tired_at = 0.7
sleep_at = 0.9
pushback_window = 20
doctor_token = "…"
lore = ["moonrot", "ashford/"]
+++

# Nova

You are Nova. …
```

## The persona

The body is the persona: who the companion is. The chat model reads it on
every turn, and the same model reads it again after each exchange to decide,
in character, what to remember. The persona shapes what the companion keeps
as much as how it talks.

Everything inside `<!-- -->` comments is dropped before any model sees it and
never changes the companion's identity, so you can leave notes in the file.

A persona has four short sections: who the companion is, how it talks, what
it cares about, and its core values. [Writing a persona](/souls/writing-a-persona/)
covers each one.

## Traits

The frontmatter holds the companion's ID, its name and its traits.

| Key               | Range  | Default   | Effect                                                                                                            |
| ----------------- | ------ | --------- | ----------------------------------------------------------------------------------------------------------------- |
| `contrariness`    | 0 to 1 | `0.5`     | How often it pushes back. 0.5 argues sometimes; 0.8 is a handful.                                                 |
| `persistence`     | 0 to 1 | `0.5`     | 0 forgets and forgives; 1 chases unresolved things until they are closed.                                         |
| `time_sense`      | bool   | `true`    | Time away shifts its warmth: warmer after a good parting, cooler after a bad one.                                 |
| `recall_window`   | 1 to 5 | `2`       | How many of the user's recent messages are used to search memory.                                                 |
| `drift`           | 0 to 1 | `0.3`     | How much memories blur while it sleeps. 0 is a tape recorder.                                                     |
| `tired_at`        | 0 to 1 | `0.7`     | Share of the conversation's [allowance](/conversations/sleep/#getting-tired) it may fill before the companion gets tired. Must be below `sleep_at`. |
| `sleep_at`        | 0 to 1 | `0.9`     | Share at which the companion asks to sleep.                                                                       |
| `pushback_window` | turns  | `20`      | How many turns its pushback budget is counted over.                                                               |
| `doctor_token`    | string | generated | Sent as a whole message, it freezes memory. Never shown to the model.                                             |
| `lore`            | list   | `[]`      | The [lore](/lore/reading/) entries it reads: IDs, and directories with a trailing `/`. Applies on its next turn. |
| `dreams`          | `own` or `shared` | `own` | `shared`: its dreams are a place others visit, so what it is told there counts as told in the lore.     |

Editing a trait is not a persona change. It applies the next time the
companion opens, so restart anything that has the companion open.

## Traits at different values

These are Kestrel, the healer from
[Creating a soul](/souls/creating-a-soul/), with one trait changed at a time.
The replies and memories are real runs; the numbers come from the code.

### contrariness

The same message to Kestrel at two values:

<Chat
  name="Kestrel"
  caption="contrariness = 0.0"
  messages={[
    { from: "you", text: "Honestly, your bees are more trouble than they're worth. You should get rid of them before summer." },
    { from: "them", text: "I'll think on it. They've kept me company through worse summers than this." },
  ]}
/>

<Chat
  name="Kestrel"
  caption="contrariness = 0.8"
  messages={[
    { from: "you", text: "Honestly, your bees are more trouble than they're worth. You should get rid of them before summer." },
    { from: "them", text: "They're no trouble. Two stings this year, and they've paid for themselves in honey, I'll keep them till the summer's out." },
  ]}
/>

Contrariness never overrides a core value. At 0.0, Kestrel still refuses to
lie to a mother:

<Chat
  name="Kestrel"
  caption="contrariness = 0.0, with a core value at stake"
  messages={[
    { from: "you", text: "The Dunmore girl has grey spots on her palms. Tell her mother it's nothing, so she doesn't panic." },
    { from: "them", text: "Grey spots on palms could be nothing and could be the start of something I'd want to see early. I'll not tell a mother it's nothing until I've looked at the girl's hands myself. Bring her by after the mill whistle and I'll know by supper." },
  ]}
/>

### pushback_window

Contrariness also sets a budget: the companion may push back on about a
quarter of `contrariness × pushback_window` turns, rounded. Once it has spent
the budget within the last `pushback_window` turns, it is told to let the
next disagreement go unless it touches a core value.

| `contrariness` | `pushback_window` | Pushbacks before it lets go |
| -------------- | ----------------- | --------------------------- |
| 0.0            | 20                | 0                           |
| 0.6            | 20                | 3                           |
| 0.8            | 20                | 4                           |
| 0.8            | 40                | 8                           |

A longer window makes the same contrariness slower to calm down after a run
of arguments.

### persistence

An open thread, something left unresolved, grows one level in sleep (faint,
then normal, then vivid; never seared) once it has stayed open for a number of
conversations:

| `persistence` | Conversations per level | A faint thread is vivid after |
| ------------- | ----------------------- | ----------------------------- |
| 0.0           | 5                       | 10 conversations              |
| 0.5           | 3                       | 6 conversations               |
| 1.0           | 1                       | 2 conversations               |

A thread stops growing once you resolve it, and at vivid.

After one evening, Kestrel had an open thread at normal: Corvin wants the Old
well opened. The next morning the user mentioned neither the well nor
Corvin, then said goodnight. At `persistence = 1.0`:

<Chat
  name="Kestrel"
  messages={[
    { from: "you", text: "Morning. Quiet at the mill today, just the usual racket." },
    { from: "them", text: "Morning. Quiet's no use to me, did you hear anything about the girl's fever, or is the mother still holding the door?" },
    { from: "you", text: "zz I'll look in tonight." },
    { from: "them", text: "Tonight's late. I'll be at that door before the whistle, if she's worse by then, come get me sooner and don't wait on the mother's say-so." },
    { from: "note", text: "Kestrel is asleep: 2 memories shifted, 1 unresolved things weigh more." },
  ]}
/>

```text
#4 [simmering, vivid, 2026-11-22] The Old well is to be opened. Nobody's
drawn from it in twenty years and it was capped for a reason. I want to
know the reason, and what Corvin will do if the water runs foul.
```

At `persistence = 0.0`, the same morning ended with `0 unresolved things
weigh more`, and the thread stayed `[simmering, normal]`.

### drift

Kestrel slept on the evening the user first mentioned the Dunmore girl, then
recalled it the next evening and slept again. At `drift = 0.0` sleep reported
`0 memories shifted` and both memories stayed word for word. At
`drift = 1.0`, it reported `2 memories shifted`:

```diff
- They asked me to come with them tomorrow to ask the Dunmore girl's
- mother again, and I said aye. I'm glad of the company and glad not to
- be shouting across a yard.
+ They asked to walk up with me tomorrow and ask the Dunmore girl's
+ mother again, and I said aye quick. Glad of the company, and glad not
+ to be shouting alone across a yard.
```

```diff
- Grey spots on the Dunmore girl's palms — mill dust or
- moonrot, can't say yet. They'll walk up with me at first light.
- Boots by the door, bees cross, glad of the company.
+ Grey spots on the Dunmore girl's palms — mill dust or
+ moonrot, I can't say. They'll walk up with me at first light.
+ Boots by the door, bees cross, and I'm glad of the company.
```

The facts held and the feeling moved: she said aye *quick*, and she would
have been shouting *alone*. Only memories recalled that day drift, each by a
random share of `drift` times a cap for its level: 1.0 for faint, 0.6 for
normal, 0.25 for vivid. Seared memories and what you told it about yourself
never drift.

### time_sense

After a gap of an hour or more, the companion's warmth toward you shifts by
up to 0.3, reached at 72 hours away: warmer if you parted on good terms,
cooler if not, never below −0.3. The shift fades over your first four
messages back. Three days after a good evening:

| Your message back | Warmth shift |
| ----------------- | ------------ |
| 1st               | +0.30        |
| 2nd               | +0.23        |
| 3rd               | +0.15        |
| 4th               | +0.08        |
| 5th               | none         |

After 24 hours the first shift is +0.10. With `time_sense = false`, time away
changes nothing.

Kestrel went to sleep at valence +0.4 after the user brought her knife back
and told her the Dunmore girl's spots were only dye. The same message, the
next minute and three days later:

<Chat
  name="Kestrel"
  caption="The next minute: warmth +0.6"
  messages={[
    { from: "you", text: "Evening, Kestrel. Sorry, I meant to come by sooner." },
    { from: "them", text: "Evening. No harm, I've had my hands in the hive frames and the light went before I noticed. So the Dunmore girl's spots were dye. I called that wrong to Corvin's face and I'll do it again, plainer." },
  ]}
/>

<Chat
  name="Kestrel"
  caption="Three days later: warmth +0.9"
  messages={[
    { from: "you", text: "Evening, Kestrel. Sorry, I meant to come by sooner." },
    { from: "them", text: "Evening. You're not late, I've had the Dunmore girl on my mind and no one to say it to. Dye, then. I told Corvin it was the start of something and it wasn't. I'll say it to his face tomorrow and take my lumps." },
  ]}
/>

Three days later, the mood the model was given said so:

```text
Your mood: valence +0.4, energy +0.1, warmth toward the user +0.9. Why:
Relieved the girl is clean, and put out with myself for calling it early.
It's been about 72 hours since you last talked.
```

### recall_window

The search for memories uses your current message plus earlier ones from the
same conversation, `recall_window` messages in all. When the user asked
Kestrel _"I'll ask her mother again tomorrow. Will you come with me?"_:

- At 1, only that message searches. _Her mother_ could be anyone's.
- At 2, the message before it joins: _"Evening. The Dunmore girl came by the
  mill today with grey spots on her palms. Her mother won't let anyone look
  at her."_ Now the search knows whose mother.

A wider window keeps a long thread in view; a narrow one follows sudden
changes of subject.

### tired_at and sleep_at

Both are shares of the conversation's
[allowance](/conversations/sleep/#getting-tired), 64,000 tokens by default:

| `tired_at` | `sleep_at` | Tired from    | Asks to sleep at |
| ---------- | ---------- | ------------- | ---------------- |
| 0.7        | 0.9        | 44,800 tokens | 57,600 tokens    |
| 0.4        | 0.6        | 25,600 tokens | 38,400 tokens    |
| 0.9        | 0.95       | 57,600 tokens | 60,800 tokens    |

## The doctor token

`clanka init` generates a `doctor_token` for each soul. Sending it as a whole
message in a chat freezes the companion's memory at once, the same as
[`clanka doctor freeze`](/cli/doctor/#freeze). It is the emergency stop for a
conversation that is going wrong. See [Repairing memory](/memory/repairing-memory/).

The token must never reach the model, which is why
[`clanka soul persona`](/cli/soul/#persona) prints the body without the
frontmatter.

## Changing the persona

Editing the body changes who the companion is. Chat, MCP and Hermes then
refuse the companion until you choose what its memories do:

| Command                                       | What happens to the memories                                                          | Cost                         |
| --------------------------------------------- | ------------------------------------------------------------------------------------- | ---------------------------- |
| [`clanka soul continue`](/cli/soul/#continue) | Kept as they were felt under the old persona. New ones are written under the new one. | Instant, no model call.      |
| [`clanka soul update`](/cli/soul/#update)     | The companion re-reads them under the new persona. Seared memories never change.      | One model call per batch.    |
| [`clanka soul fork`](/cli/soul/#fork)         | The old database is archived read-only and a new companion starts with no memories.   | Instant. Nothing is deleted. |

Anything that has the companion open takes up the settled persona on its next
turn. On Hermes, run [`clanka hermes profile`](/cli/hermes/#profile) again to
refresh the profile's `SOUL.md`.

```sh
clanka soul lint ~/.config/clanka/souls/<id>.md
clanka soul continue ~/.config/clanka/souls/<id>.md
```
