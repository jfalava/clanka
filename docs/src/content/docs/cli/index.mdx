```sh
clanka <command> [arguments]
```

Start with [`clanka init`](/cli/init/), edit the `soul.md` it prints, then
talk with the companion through [`clanka chat`](/cli/chat/) or serve it to an
MCP host with [`clanka mcp`](/cli/mcp/).

## The soul argument

Most commands take the companion's `soul.md` as their first argument: the
path that `clanka init` prints, and that [`clanka list`](/cli/list/) shows
again.

```sh
clanka memories ~/.config/clanka/souls/<id>.md
```

## Command reference

- **Set up:** [init](/cli/init/) creates a companion. [soul](/cli/soul/)
  lints, drafts and prints a soul, and settles a persona change.
  [embedding](/cli/embedding/) downloads the embedding model.
- **Talk:** [chat](/cli/chat/) in the terminal. [mcp](/cli/mcp/) for an MCP
  host. [hermes](/cli/hermes/) for Hermes profiles and Nightshade.
- **Inspect:** [memories](/cli/memories/) prints what a companion remembers.
  [recall](/cli/recall/) shows what one query brings up.
  [eval](/cli/eval/) measures recall over a cases file.
  [tics](/cli/tics/) finds prose tics in replies.
- **Repair:** [doctor](/cli/doctor/) freezes, logs, rolls back, rewrites and
  deletes memories.
- **Move:** [list](/cli/list/) shows the companions on this machine.
  [export](/cli/export/) and [import](/cli/import/) move one to another
  machine.

## Help

Every command explains itself, in three equivalent ways:

```sh
clanka help doctor rollback
clanka doctor rollback help
clanka doctor rollback --help
```

## Program status

On a terminal, the commands that take a while say what they are doing over
the [Program Status Protocol](https://www.superlogical.com/rex/docs/build/program-status)
(OSC 7501), and set the window title to match. Rex shows it on the tab and
in the session picker. A terminal that doesn't know the sequence ignores it.

| Command                                         | What it reports                                                       |
| ----------------------------------------------- | --------------------------------------------------------------------- |
| `chat`                                          | Replying, replied or no reply, and the reflections in the background. |
| `soul update`                                   | The share of memories re-read and the model calls made.               |
| `doctor reinterpret`                            | The model calls made.                                                 |
| `doctor reembed`                                | The share of memories embedded.                                       |
| `soul draft`                                    | The round.                                                            |
| `init`, `embedding`                             | The share of each model file downloaded.                              |
| `hermes profile`, `nightshade` and `refresh`    | The `hermes` call under way. `refresh` adds the share of profiles.    |

A run ends as `done` with one line of what it did, as `error` with the
reason, or as `idle` after Ctrl-C. A model request that waits to be retried
shows why.

Nothing is reported when stderr is not a terminal, when `TERM` is `dumb`, or
with [`CLANKA_PROGRAM_STATUS=0`](/configuration/#clanka_program_status).
`clanka mcp` never reports.

## Global flags

### `--help`, `-h`

Print help for the selected command without running it. `-h` prints a
summary.

```sh
clanka chat --help
```

### `--version`, `-V`

Print the version.

```sh
clanka --version
```
