---
title: chat
description: Talk with a companion in the terminal, on its configured model.
---

```sh
clanka chat [--budget <tokens>] <soul>
```

Needs a [`[model]`](/configuration/#model) section in `config.toml`. Type a
message and press Enter. Each reply is remembered in the background.

It refuses to start if the persona changed since the companion's memories
were written. Settle the change with [`clanka soul`](/cli/soul/) first.

```sh
clanka chat ~/.config/clanka/souls/<id>.md
```

After you send a message, a [progress row](/cli/#progress) runs until the
first words of the reply arrive. On a terminal that shows
[program status](/cli/#program-status), such as Rex, the tab says whether the
companion is replying or has replied.

## Flags

### `--budget <tokens>`

Estimated tokens the memory context may use per turn.

- Default: `6000`

```sh
clanka chat --budget 4000 ~/.config/clanka/souls/<id>.md
```

## In the conversation

### `/sleep`

Ends the conversation and turns it into memories. See
[Sleep](/concepts/sleep-and-dreams/#sleep).

### `/triage`

Prints what clanka did lately for this companion: its state now (in a
conversation, dreaming, frozen or none open) and its last 15
[diagnostics events](/cli/diagnostics/), such as which markers a message used,
whether a `zz` ended a dream and how each pass over memory went. It holds no
conversation text, only counts and fixed words, so you can paste it into a
bug report. It isn't a turn: nothing is recorded and no model is called.
Above, the `zz` ended the dream (`dream goodnight spent`) and the wake pass
ran.

```text
you> /triage
clanka 0.1.10 triage for Nova
Now: no conversation open.
Last 3 events, oldest first (UTC):
21:03:25 turn_begin context_tokens=499 dream goodnight host=chat message_chars=10 ms=41 outcome=open spent
21:03:31 turn_end host=chat ms=3 reply_chars=212
21:03:58 memory_pass.wake host=chat ms=26810 ok=2 rounds=2
```

With diagnostics off (`[diagnostics] enabled = false`), it shows the state only.

### `zz`

At the start of a message, says goodnight: the companion answers it, then
falls asleep as on `/sleep`. In a dream, it wakes instead. Any case, and what
follows is your goodnight.

```text
you> zz night, see you tomorrow
```

### The doctor token

Sending the soul's `doctor_token` as a whole message freezes the memory and
quits without recording anything. See
[Repairing memory](/guides/repairing-memory/).

### `>>N`

At the start of a message, asks for a reply of about N paragraphs. A space
after `>>` is fine: `>> 3` is the same marker.

```text
you> >>3 Tell me about the cello lesson.
```

### `~~`

As the first message after sleep, starts a
[dream](/concepts/sleep-and-dreams/#dreams). What you write is what happens
to the companion, as "you", and it lives it without knowing it dreams. The
space after `~~` is optional; only `~~text~~`, closed like strikethrough, is
plain text.

```text
you> ~~ You're standing in your mother's kitchen. It is too quiet.
```

### `<<`

In a dream, shows the companion an echo of the past. The space after `<<` is
optional; only `<<text>>`, closed like typed guillemets, is plain text.

```text
you> << >>3 Years ago, in this room, the judge reads the sentence aloud.
```

### `||`

Anywhere in a waking message, text between `||` and `||` is said out of the
companion's earshot. It plays along without hearing it, and never keeps it.

```text
you> Dinner was fine. ||I haven't told her about the job yet.||
```
